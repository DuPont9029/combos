# combos

Yu-Gi-Oh! combos transcribed from YouTube videos, one folder per deck.

For each combo:

- `<combo>.md` — Obsidian note (summary, starting hand, step-by-step combo, end board, notes)
- `<combo>.pdf` — the same note as PDF
- `<combo>.helios.txt` — combo code for the Helios combo trainer (Combos → Import)
- `<combo>.helios.json` — the same combo, readable
