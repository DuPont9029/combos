# combos

Yu-Gi-Oh! combos transcribed from YouTube videos, one folder per deck.

For each video:

- `<combo>.md` — Obsidian note: summary, decklist (card images), every combo as a step-by-step
  schema like the Helios combo trainer (starting hand → numbered steps with choices → end board),
  and the notes from the video
- `<combo>.pdf` — the same note as PDF
- `<combo>_N.helios.txt` — combo code for the Helios combo trainer (Combos → Import), one per combo
- `<combo>_N.helios.json` — the same combo, readable

`cards/` holds the card images (from YGOPRODeck), shared by all decks.
